# 本地再铸  V1.0

面向 **Intel i5-12600KF + NVIDIA RTX 4060 Ti** 的本地短剧再铸工作台。两条入口：

1. **导入现成视频**：解析提取、人物建库、**L1 人物替换**、合成导出（V0.1 闭环，仍然完整可用）
2. **按剧本 / 分镜生成新集**：套用四级模板，先生成静音画面，再贴对白与字幕

主界面是 **PySide6 桌面工作台**（深色、原创布局）。产品名称是「本地再铸」，不模仿任何第三方软件的名称或界面。

> L1 的「人物替换」是本地换脸，**不是**「提取了3D模型」。L2 才叫「3D头像」，L3 叫「3D道具生成」。

---

## 能做的事

| 阶段 | 作用 |
| --- | --- |
| 01 扫描与补资料检查 | 扫描剧目文件夹；缺什么会**直接写出文件名**，例如「缺少 5.png、6.png」 |
| 02 解析提取（切镜/字幕） | 切镜 + ASR + OCR，对齐成一份 SRT（导入视频） |
| 03 人物提取与建库 | 跟踪与聚类，确认姓名并勾选授权 |
| 04 人物替换 | 只对**已授权**人物做 L1 本地换脸 |
| 05 合成导出 | 混流音轨，写出成片和旁路 SRT |
| 06 模板套用 | 四级模板（剧本 / 角色 / 场景 / 分镜），任务钉住所用版本 |
| 07 按剧本生成（先静音） | ComfyUI 工作流；否则「**分镜预览成片**」（参考静帧推拉，不是完整图生视频） |
| 08 贴轨与字幕 | 对白字数预检，不加速音频；可导入 wav 或跳过配音只出 SRT |
| 09 成本表 / 剪映工程导出 | `cost.xlsx` 与日志数字一致；剪映草稿目录（不承诺打开所有版本） |

另外还有：任务队列、状态机、断点续跑、CPU/GPU 错峰（默认 1 个 GPU 任务）、质量终检与单镜重跑、L2 3D头像资产、L3 3D道具试点、可选云通道（默认关，调用前确认预估）、可选上传（默认关，只发往你指定的文件夹 / webhook / 命令）。

### 用词与能力边界

- 未连接 ComfyUI 时，按剧本生成的画面是「分镜预览成片」，**不是**默认的 Wan / AniCrafter 高质量图生视频（8GB 显存也不适合把那条当作默认路径）。
- L2「3D头像资产」= 关键点 + 漫反射贴图 + 驱动配置 + 占位脸卡。未放入官方 FLAME 时，**不是**生产级完整网格。程序不捆绑许可证受限模型。
- L3 写出的网格是「试点/占位结果」，不是成品角色模型，也不会自动绑骨骼。

## 硬件与显存

- 默认使用 `configs/4060ti-8g.yaml`。只有确认自己是 16GB 时，再改用 `configs/4060ti-16g.yaml`。
- 无独立 GPU 时，自检会降为**基础档**：切镜、字幕、分镜预览成片可用；L2 驱动和 ComfyUI 重生成禁用，不会崩溃。
- 默认同一时间只跑 1 个 GPU 任务。GPU 忙时，CPU 可以预处理下一集。

## 推荐文件夹与示例

导入视频时，剧目目录仍建议包含视频、`参考图/` 和可选的 `名单.yaml`（格式见 `examples/names.yaml`）。

按剧本生成可直接使用附带示例（来自用户自己的第 1 集材料，不是第三方产品包）：

```
examples/开局即打-第1集模板/     # 四级模板 + 参考图 + 分镜/对白
examples/开局即打-示例剧目/
```

在桌面点「按剧本生成新集」，模板包选上面这个目录。约 90 秒、旁白只在 F1、无 BGM、一镜一动作、竖屏 720×1280。

没有名单或参考脸时，**仍然可以先跑 02 / 03**。要做「04 人物替换」或生成 L2 资产，必须先确认姓名、勾选授权（`自有拍摄` / `已授权` / `自有生成角色`）。

## Windows 安装

请先准备：

1. **Python 3.11**（推荐；3.12 一般可用。**不要用 3.13**）
2. 把 `python` 加入 PATH
3. 安装 **ffmpeg**，保证 `ffmpeg` 和 `ffprobe` 都在 PATH 里。可从 https://www.gyan.dev/ffmpeg/builds/ 下载
4. 已安装 NVIDIA 驱动，`nvidia-smi` 能跑（无独显也可装，会降为基础档）

然后在项目根目录执行：

```bat
scripts\install_windows.bat
```

脚本会创建 `.venv`，安装 **CUDA 12.4** 版 PyTorch 和依赖（含 openpyxl 等）。安装后：

```bat
.venv\Scripts\activate
python -m recast doctor
python -m recast ui
```

请预留至少 10 GB 磁盘，作品目录尽量放在固态硬盘上。大模型权重不在压缩包里，第一次跑相关步骤时再下载。

## 桌面工作台里怎么用新功能

```bat
python -m recast ui
```

- **模板编辑器**：编辑四级模板、校验、导入/导出模板包、把当前包套到勾选的剧目。
- **按剧本生成新集**：选择模板包（以及可选的分镜、对白文件），加入队列后勾选 06–08（或「全部阶段按序执行」）再开始。
- **成本表**：查看 / 导出 `cost.xlsx`，数字来自 `runs` 日志。
- **质量终检**：查看被标记的镜头并单镜重跑。
- **人物库**：「生成 3D头像资产」。同一人物 ID 可跨集复用。偏低会标出。
- **3D道具（试点）**：按提示词或图片导出占位网格。
- **设置**：硬件档、ComfyUI 地址、云通道密钥（加密保存）、上传方式。云通道与自动上传默认关闭。任何云调用会先问预估。

网页备用：`python -m recast ui-web` 或 `python -m recast ui-simple`（完整新窗口请用桌面端）。

## 命令行

```bat
python -m recast process INPUT.mp4 --face REF.jpg --out OUT.mp4 --config configs/4060ti-8g.yaml
```

常用参数与 V0.1 相同（`--only`、`--workdir` 续跑、`--skip-replace`、`--burn-subs` 等）。`--only` 也可写 `template,generate,dub,export`。若所选阶段的产物已经在工作目录里，默认会跳过并提示「无需重跑」；需要推倒重来时加上 `--force-rerun`（工作台里对应「强制重跑」开关）。

## Windows 打包

```bat
scripts\build_windows.bat
```

生成 onedir 目录 `dist\本地再铸\`。大模型权重不打进包。把 `ffmpeg.exe` / `ffprobe.exe` 放到项目或输出目录的 `ffmpeg\` 下也可以。

## 使用注意

- 核心流程断网、不填任何云密钥也能跑完。
- 请使用 Python 3.11，不要用 3.13。默认按 8GB 显存配置。
- **InsightFace / inswapper 请自行阅读其许可证**后再用于你的素材。
- 升级时数据库会自动迁移，V0.1 的 `recast.db` 里未完成的任务可以续跑。作品目录不会被安装覆盖。
- 工作目录名使用 ASCII（序号或路径哈希），原始中文文件名写在 `meta.json` / `source_meta.json` 里供界面显示。路径含中文时，会在该工作目录里为视频建立 `input.mp4` 别名（硬链接 / 符号链接 / 复制），并校验别名仍指向同一源文件。
- 「停止当前」只取消正在跑的那一条任务，队列里尚未开始的任务会接着执行，不会被一起清掉。
- 阶段之间会丢掉模型引用并做垃圾回收。`torch.cuda.empty_cache()` 只对已经释放的 PyTorch 显存块有效，对 ONNX Runtime / InsightFace / faster-whisper（CTranslate2）会话并不生效，这些要等对应对象析构后才会还显存。
- `onnxruntime-gpu` 锁定在 `>=1.20.0,<1.21`（CUDA 12 档）。1.27 起的默认轮子面向 CUDA 13，在 cu124 的 PyTorch 环境里会缺 `cublasLt64_13.dll`，然后悄悄回到 CPU。
- 网页工作台默认只监听 `127.0.0.1`。若改成 `--host 0.0.0.0`，启动时会给出警告：目录浏览和打开路径接口没有鉴权。
- 再扫描其他目录时，原来队列里不属于当前根目录的任务（含参考脸、花名册等设置）会保留；删除请用「移除勾选」。

覆盖测试（不需要 GPU 或模型）：

```bat
.venv\Scripts\activate
python -m pytest
```

更多说明见 `docs/V0.5说明.md`、`docs/V1.0说明.md` 和 `docs/方案与架构V1.0.pdf`。
