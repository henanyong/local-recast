# 本地再铸 V1.0 说明

产品名称使用「本地再铸」。用词红线仍然有效：L1 叫「人物替换」，不是「提取了3D模型」；L2 叫「3D头像」；L3 叫「3D道具生成」。

## 已实现

- **L2「3D头像」**：用已授权角色的参考脸，生成可复用的头资产，绑定人物 ID（参数、关键点、漫反射裁切、简单脸卡 OBJ、驱动配置、质量分、来源说明）。优先 InsightFace 关键点；未安装时走中心框回退，质量分会偏低。可选 LivePortrait 驱动：未安装时自检/设置会说明，资产仍保存待以后驱动。人物库显示 3D 完整度（已齐 / 偏低 / 缺失），不再写「未建设」。
  - **诚实口径**：关键点 + 漫反射 + 驱动配置称为「3D头像资产」，在未放入官方 FLAME 时**不是**生产级完整网格。本程序不捆绑许可证受限的 FLAME / SMPL-X。若你已从官方取得 FLAME，把它放到 `models/flame/`，说明见资产目录里的 `FLAME说明.txt`。
  - 验收目标：一个角色生成一次 L2 资产，按人物 ID 跨两集复用。
- **L3「3D道具生成」试点**：独立窗口，按图片或提示词生成静态道具/场景网格。若配置了 ComfyUI Hunyuan3D / Tripo 工作流则走该后端；否则写出任务说明和带贴图的简单盒体，明确标记为「试点/占位结果」，不会当成成品角色模型，也不会给人物自动绑骨骼。
- **云备选通道**（火山、DeepSeek、通用 OpenAI 兼容）：在设置里填写 AK/SK 或 API Key。密钥在 Windows 上优先用 DPAPI 加密，否则用本地密钥文件（Fernet 或同等），**不进日志、不进导出**。默认关闭。任何云调用先弹出预估并需确认。每次调用写入 `runs` 与成本表。核心流程在没有密钥时仍可完全离线跑完。
- **自动上传**：可选最后一步，**默认关闭**。不做脆弱的官方平台登录。提供：复制到指定文件夹，以及可选的用户自定义 HTTP webhook / 上传命令。只发往用户自己的目标。关闭时开关保持关闭。
- **自检向导 / doctor 升级**：检测 GPU/CPU 档位。无独显降为「基础档」，禁用或隐藏 L2 驱动与重生成，并给出说明，不会崩溃（按剧本生成改走分镜预览成片）。检查磁盘空间、缺失模型并给出可行动修复、选择作品目录。升级时自动迁移数据库，V0.1 的 `recast.db` 可继续，老任务能续跑。

## 数据库升级

打开旧库时自动把 schema 升到当前版本（新增模板版本、镜头字段、runs 的时长与费用等列）。程序目录可覆盖安装；作品目录与模型仓库不动。

## 硬件

默认仍是 Intel i5-12600KF + RTX 4060 Ti 8GB（`configs/4060ti-8g.yaml`）。请使用 Python 3.11，不要用 3.13。8GB 上不要把高规格图生视频当作默认路径。
