# 使用说明（local-recast 2D 人物替换 + 设定板）

**适用**：`C:\Users\LookingUP\Desktop\local-recast\local-recast`  
**项目自带 venv**：`.venv\Scripts\python.exe`（下文简写为 `python`）

---

## 0. 先自检

```bat
cd C:\Users\LookingUP\Desktop\local-recast\local-recast
.venv\Scripts\python.exe -m recast doctor
```

会打印 Python / CUDA / ffmpeg / 数据库 / 模型缺什么。最后一行给"自检通过"再往下走。

---

## 1. 图形界面（推荐先跑这个）

```bat
.venv\Scripts\python.exe -m recast ui
```

打开后是深色三栏工作台。**人物库**是主入口，右侧检查器按步骤分组：

| 步骤 | 按钮                                    | 前提       | 产出                                 |
| -- | ------------------------------------- | -------- | ---------------------------------- |
| 1  | `[建人物文件夹]`                            | 选中人物     | `output/characters/<名字>/`          |
| 2  | `[抠像]`                                | 有文件夹     | `cutout/*.png`                     |
| 3  | `[生成 3D 模型]` / `[导入 3D 模型]`           | 有抠像 / 任意 | `model/model.glb`                  |
| 3  | **`[生成设定板]`**                         | 有文件夹     | `sheet/turn_*.png` + `sheet.json`  |
| 4  | `[衣服打标签…]` `[试听声音]` `[调节音色]` `[编辑对话]` | 有文件夹     | 对应资产                               |
| 5  | `[绑定服装到模型]` **`[换装预览…]`**             | 有衣服      | `replace_preview/before/after.png` |

两个新按钮的行为：

- **`[生成设定板]`**：有 GLB 就渲染 4 个角度转盘（自动识别 Z-up 并扶正），同时从照片里量主色和肤色。发色/体型故意不做测量（没分割就不猜）。**没有 GLB 也能建**，只是只有外观字段。
- **`[换装预览…]`**：挑一张图当帧，把 `costume/` 里的服装配色换上去，生成 before/after 两张对比图，**跑完自动打开 after**。状态栏会报背景损伤和接缝增量。

顶部还有一行批量入口：`[导入视频/照片]` → `[自动定义人物]`（一次跑完人脸聚类、名字建议、衣服打标签、说话人切声音）。

## 2. 命令行：单帧试验（最快看出效果）

## 3. 命令行：整段跑（真实产能）

```bat
.venv\Scripts\python.exe scripts\demo_replace_clip.py ^
  --video "C:\Users\LookingUP\Desktop\demo\1\装穷提亲，娶到全家嫌弃的她 第1集_1.mp4" ^
  --start 88 --frames 48 ^
  --costume "examples\开局即打-示例剧目\参考图\02-陈秋微.jpg" ^
  --redetect 4 ^
  --out outputs\_demo\clip
```

输出 `outputs\_demo\clip\replaced.mp4` + 终端逐帧审计摘要 + 最差帧清单 + 一集耗时外推。

### 参数怎么调

| 参数           | 默认        | 说明                                             |
| ------------ | --------- | ---------------------------------------------- |
| `--part`     | `upper`   | `upper` 上半身 / `lower` 下半身 / `full` 全身          |
| `--person`   | `0`       | 画面里的第几个人（按面积**从大到小**数，0 是最大的）                  |
| `--mode`     | `recolor` | `recolor` 只换色（推荐）；`texture` 拉伸纹理（需对齐的服装图，一般别用） |
| `--redetect` | 6         | 每几帧重检测一次。**小=更准更慢**，快动作镜头用 2–4                 |
| `--smooth`   | 0.55      | 掩码平滑强度。大=更稳但更滞后，0=不平滑                          |
| `--delivery` | 关         | 交付模式：拒绝非商用模型（会退到 GrabCut，很慢）                   |

## 4. 模型文件放哪

**分割模型**（放 `models\segmentation\`，自动按优先级选）：

| 文件                        | 许可             | 说明               |
| ------------------------- | -------------- | ---------------- |
| `birefnet.onnx`           | MIT，**可商用**    | 首选。放进去自动优先于 RMBG |
| `yolo11n-seg.pt`          | AGPL-3.0       | 快（~30ms），商用需企业授权 |
| `selfie_segmenter.tflite` | Apache-2.0，可商用 | MediaPipe，文件最小   |

**换脸模型**：`models\inswapper_128.onnx` 或 `~\.insightface\models\inswapper_128.onnx`（非商用，需授权）

**RMBG-1.4**（非商用）现在会自动在 `~/TripoSG/pretrained_weights/RMBG-1.4/onnx/` 找到。

**强制 CPU**（GPU 被别的东西占用时）：

```bat
set RECAST_RMBG_CPU=1
```

## 5. 怎么看结果好不好

终端/状态栏这几个数就是判断标准：

| 指标      | 合格线         | 不合格说明                   |
| ------- | ----------- | ----------------------- |
| 背景损伤    | **< 2%**    | 人物轮廓外的像素被改了，会有光晕        |
| 接缝增量    | **< 1.15×** | 相对原帧新增的边缘，>1.15 说明颈部有硬边 |
| 覆盖率     | **> 85%**   | 低于这个会露出原演员的衣服边          |
| verdict | `ok`        | `review` 就该人工看一眼，别直接交付  |

`review` 的帧会列在"最差帧"里，按接缝从高到低排——**只看这几帧就够了**，不用看整段。

## 6. 常见问题

| 现象                   | 原因                       | 处理                                   |
| -------------------- | ------------------------ | ------------------------------------ |
| 画面里的人没被换             | `--person` 选错            | 换 `--person 1` / `2` 试               |
| 旁边的人也被染了             | 分割把两个人算成一个               | 已经用框归属修过；若仍出现，调小 `--redetect`        |
| 衣服边缘抖                | 掩码逐帧跳                    | 调大 `--smooth`，调小 `--redetect`        |
| 白领子被染色               | 中性色保护没生效                 | 检查是不是纯灰衣物（保护会刻意跳过）                   |
| 快了 10 倍慢             | 走了 GrabCut               | 看终端"分割后端"，缺模型；或用了 `--delivery`       |
| 报 `mp.solutions` 不存在 | mediapipe 0.10.35 移除了旧接口 | 影响的是 B4 老路径（`composite_clip`），新管线不走它 |

## 7. 一次完整流程（建议顺序）

```
doctor 自检
  → ui 打开，导入视频，[自动定义人物]
  → 选人物，[建人物文件夹] → [抠像]
  → [生成设定板]（看 4 个角度和主色对不对）
  → 命令行 demo_replace.py 单帧调 --person / --part
  → 满意后 demo_replace_clip.py 跑整段
  → 看最差帧，只复看那几个
```
