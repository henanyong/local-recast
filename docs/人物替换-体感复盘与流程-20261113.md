# 人物替换：体感复盘与正确流程（2026-11-13）

## 结论

体感差的根因不是模型不够强，而是**流程把三个决策压在同一帧里做**：分割、选哪件衣服、怎么融合，全部逐帧临时决定，而且没有任何逐帧验收门槛。只要有一条不达标，用户看到的就是"一眼假"。

正确的做法是把它拆成**一次定义 + 逐帧执行 + 逐帧拦截**三段。本文给出门槛数值，全部来自今天的实测。

---

## 一、问题陈述（实测证据，不是推测）

| 现象 | 实测根因 | 证据 |
|---|---|---|
| 换完几乎看不出变化 | 选的参考衣与原衣**色相过近** | 焦糖 a=139/b=150 vs 原衣酒红 a=150/b=132；22.9% 像素被改，但 ΔE 很小 |
| 出现矩形色块 | 颈部切线是**水平硬边**，且外套肩部在这条线以上 | `upper` 区域外接框填充率 92%（正常人物轮廓 40–70%） |
| 花衬衫被一起染色 | 颜色聚类**分不开同色系印花** | 酒红开衫与衬衫红花落到同一簇；改为按簇换色后变成花斑 |
| 换人后像贴纸 | insightface 默认贴回蒙版过硬，源脸比目标亮 | 修复前脸颊有硬边矩形；改成羽化 + Lab 均值匹配后消失 |
| 一集要 200 分钟 | **每帧重载 554MB 权重** | 已修：后端缓存，降到 30 分钟 |

**一句话**：不是"效果不好"，是"没有规格、没有门槛、没有拦截"。

---

## 二、正确流程（建议替换现有链路）

### 阶段 0　角色规格（每角色一次，不是每帧）

| 项 | 内容 | 落盘 |
|---|---|---|
| 身份 | 参考脸（正脸，≥512px） | `face/` |
| 服装 | 款式描述 + 目标色 + 材质 | `meta.costume` |
| 声音 | 音色样本（10 秒以上） | `voice/` |
| 可替换性 | 脸占比、遮挡率、色差 ΔE | `meta.feasibility` |

**关键**：这一步就要判断"这次替换能不能成立"。参考衣与原衣 ΔE < 8 时，直接提示"换色看不出，请换一件"——而不是跑完再说。

### 阶段 1　素材体检（每集一次，30 秒）

抽样 12 帧，输出：人物数、脸尺寸、遮挡率、镜头稳定性。任何一项不达标，先换集或换段，不要进逐帧。

### 阶段 2　逐帧执行

```
检测（自适应节奏） → 身份对齐 → 服装重着色 → 融合 → 质检
```

今天的修正：检测从"框归属"换成**逐实例掩码**（yolo11n-seg），双人镜头的竖直硬边消失；换脸后端改为常驻，不再每帧加载。

### 阶段 3　逐帧质检（这是现在最缺的一环）

| 指标 | 门槛 | 不达标时 |
|---|---|---|
| 换脸/换装区域外的像素变化 | **必须 = 0** | 硬拦截，不许入片 |
| 脸↔颈边界梯度增量 | < 1.15× | 进复看队列 |
| 服装区域填充率 | 70–95% | 判定分割失效，换后端重跑该帧 |
| 相邻帧身份相似度 | > 0.90 | 闪烁，进复看队列 |
| 单帧耗时 | < 400ms | 超预算说明后端选错 |

**只有五项全过才写入成片**。今天的成片是"先写完再统计"，这正是体感差的直接原因。

## 三、体态与声音（用户提出的两个新维度）

### 体态

不做 3D 全替换（已证伪：8GB 上生成资产是低模，接缝是身体的 4 倍）。可行的是**局部 warp**：

- 用姿态关键点取肩线/髋线，做纵向比例与宽度调整
- 只改轮廓，不改像素来源，因此不引入 CG 感
- 风险：背景会被拉伸，需要按人物掩码限制在身体内

**验收**：肩宽变化 ±10% 时，背景位移像素 < 0.5%。

### 声音

先做**音色替换**，不做口型：

- 提取 `voice_embedding` → TTS 重建同语调同语速的新音色
- 口型同步（MuseTalk）留到第二阶段，因为它对每帧的算力要求是现在的 3 倍

**验收**：同一句话换音色后，时长偏差 < 5%，听不出机械感（人工 5 人盲测）。

## 四、非目标（本次不做，附重启条件）

| 不做 | 原因 | 重启条件 |
|---|---|---|
| 3D 全人物替换 | 8GB 上资产是低模，接缝必然 | 有写实 GLB 资产 + 可接受 10 倍耗时 |
| 服装款式生成（西装→古装） | 需要生成式重绘，单帧 5–6 小时 | 换 24GB 卡或走云端 |
| 实时预览 | 单帧已 300ms+ | 不做 |

## 待确认清单

1. **观感底线**：中近景不可辨 vs 整体像就行？前者要求逐帧质检全绿，后者可放宽。
2. **单集时长上限**：现在 30 分钟/集（含换脸）。能否接受？不能则要先降分辨率或只换近景帧。
3. **许可证**：yolo-seg 是 AGPL、rmbg 非商用、inswapper 非商用。仅自用无碍，对外交付需替换。
4. **体态调整的幅度预期**：±10% 还是 ±30%？后者超出 warp 能力。
5. **声音先做音色还是先做口型**：两者算力差 3 倍。
