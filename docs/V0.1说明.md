# 本地再铸 V0.1 说明（对照架构方案第 1–15 章中的首期范围）

本文是 V0.1 落地说明。完整方案文档的文件名约定为 `docs/方案与架构V1.0.pdf`。若构建环境里未能放入原 PDF，以本文和仓库实现为准，覆盖方案中 V0.1 已承诺的部分；V0.5 / V1.0 能力只保留占位，不会伪装成已可用。

产品名称使用「本地再铸」，不使用、不模仿任何第三方软件的名称、品牌或界面布局。

## 范围（第 15 章验收对应）

已实现：

- 剧目文件夹扫描，按子目录识别剧目与集数
- 资料完整性检查：缺文件时进度文案写出具体文件名（如「缺少 5.png、6.png」），不用含糊的「资料不全」
- 切镜：优先 PySceneDetect，失败或不存在时 FFmpeg scene 滤镜回退
- OCR + ASR 双路字幕并对齐；RapidOCR 未安装时降级为仅 ASR，doctor 会提示
- 人脸聚类进入人物库，需人工确认姓名
- 新人物必须勾选授权（自有拍摄 / 已授权 / 自有生成角色）；人物替换只作用于已授权角色
- 单人 L1 人物替换（本地换脸）并合成导出一集
- 任务队列、默认并发 1（设置中最多 2）
- 每步写入检查点（步骤名、输入指纹、输出路径）；输入未变且产物仍在则跳过
- 中途关机后再开：处理中恢复为待执行，可续跑
- 停止当前任务 → 待执行，不是失败
- 单步失败最多重试 2 次，随后将该集标为「待人工检查」，不因单镜直接把整部剧打成失败（磁盘满、模型缺失等不可恢复错误除外，进入失败并写明原因）
- 「清除已完成」独立按钮 + 确认框；取消勾选不删除成片
- PySide6 桌面主界面（中文、深色原创工作台）
- Windows 安装脚本与 PyInstaller onedir 打包脚本（需在用户电脑上生成 exe，仓库不附预编译包）
- `python -m recast doctor` 与首次运行自检
- 离线可跑，云 API 显示「未配置」，不要求密钥
- 自动上传默认关闭且禁用

未在 V0.1 实现（界面中禁用或标明未建设）：

- 四级模板与按剧本生成新集
- 成本表、剪映工程导出
- 云通道计费、自动上传
- L2 3D 头像、L3 3D 道具生成（人物库里 3D 资料显示「未建设」）
- 说话人分离（预留钩子，不引入脆弱的 pyannote 依赖）

## 用词红线（第 6 章）

- L1 称为「人物替换」，**禁止**把换脸说成「提取了3D模型」
- L2 称为「3D头像」（后续版本）
- L3 称为「3D道具生成」（后续版本）

## 状态机（第 9 章）

`待补资料` → `待执行` → `处理中` → `已完成`  
旁路：`待人工检查`、`失败`。规则见上文与 `recast/core/state_machine.py`。

## 默认硬件档

`configs/4060ti-8g.yaml`。16GB 配置仅作为可选文件存在，不要默认假设 16GB。

## 数据存储

SQLite（默认 `outputs/store/recast.db`）包含：`dramas`、`tasks`、`shots`、`subtitles`、`characters`、`character_assets`、`templates`（可空）、`runs`、`checkpoints`、`settings`、`logs`。

## 许可证提醒

InsightFace / inswapper 权重在首次「人物替换」时按需下载，不随仓库分发。使用前请自行阅读其许可证。
