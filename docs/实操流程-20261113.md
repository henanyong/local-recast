## 3 单帧换装（调参最快）

```bat
.venv\Scripts\python.exe scripts\demo_replace.py ^
  --video "C:\Users\LookingUP\Desktop\demo\1\装穷提亲，娶到全家嫌弃的她 第1集_1.mp4" ^
  --time 90 ^
  --costume "C:\Users\LookingUP\Desktop\demo\测试素材\服装\04-焦糖长风衣.png" ^
  --person 0 --part upper
```

常用参数：

| 参数 | 含义 |
|---|---|
| `--time 90` | 取第 90 秒那一帧 |
| `--person 0` | 画面里第几个人，按占有前景从大到小 |
| `--part upper/lower/full` | 上身 / 下身 / 脖子以下全换 |
| `--backend auto` | 默认。按质量排：`yolo-seg`（已下载 6.2MB，34ms，逐实例）→ `birefnet+yolo` → `rmbg+yolo` → `mediapipe-tasks` → `grabcut`（3.3s，无模型兜底） |
| `--mode recolor/texture` | 默认 recolor（保留褶皱光影）；texture 需要对齐的服装图 |

产物在 `outputs\_demo\`：`replace_ab.png`（左右对比）、`replace_zoom.png`（放大）。

## 4 只看三个数

```
分割：yolo-seg，画面里 3 个人，选中第 1 个
区域：upper  填充率 92%
参考服装色 a=139.0 b=150.0  保住皮肤 73192 px / 保住中性色 94617 px
审计：背景损伤 0.000%  接缝 3.42 -> ok
```

| 指标 | 合格线 | 含义 |
|---|---|---|
| 背景损伤 | < 2% | 人物以外被改动的像素比例。recolor 通常 0.000% |
| 接缝 | 相对原帧增量 < 1.15× | 颈部边界梯度 / 身体纹理梯度。**原帧自身就有 3.2**，所以只看增量 |
| 填充率 | 参考值 | 区域占自身外接框的比例。躯干本来就接近矩形，70–95% 正常；到 100% 且四边都是直线才说明分割漏到背景 |

`verdict: ok` 才不用人工复看；`review` 就看 `problems` 里哪一条超了。

## 5 判定

**三项达标** → 跑整段：

```bat
.venv\Scripts\python.exe scripts\demo_replace_clip.py ^
  --video "C:\Users\LookingUP\Desktop\demo\1\装穷提亲，娶到全家嫌弃的她 第1集_1.mp4" ^
  --start 88 --frames 48 ^
  --costume "C:\Users\LookingUP\Desktop\demo\测试素材\服装\04-焦糖长风衣.png" ^
  --redetect 4 --out outputs\_demo\clip
```

出 `replaced.mp4` + 逐帧审计。实测 48 帧：12 次检测 / 36 次复用，需复看 0 帧，
外推 168 秒一集约 **23.9 分钟**。

**任一项不过** → 按顺序试：

1. 换一帧（景别更紧、背景更干净）——零成本，最有效
2. `--backend grabcut`
3. 补分割权重：`yolo11n-seg.pt` 或 `birefnet.onnx` 放进 `models\segmentation\`，代码不用改

## 6 这批素材实测到的两个真问题

**一、框归属会切出竖直硬边（已修）。** `rmbg+yolo` 分的是整块前景，靠"像素归给最小框"区分人，
双人重叠时会留下一条竖直直边——90s 那帧整条左边缘都被切走。
下载 `yolo11n-seg.pt` 后自动改用逐实例掩码，问题消失，而且快一倍（34ms vs 62ms）。
RMBG 仍保留作商用/边缘优先的可选项。

**二、`split_by_colour` 分不清"衣服"和"花纹"。** 酒红开衫 + 花衬衫那一帧，
按颜色聚类会把开衫和衬衫上的红色花朵分到同一簇——它分的是颜色，不是衣物。
素色穿搭上没问题，印花上不要指望它分件。

所以：**素色衣物是这套方案的舒适区**，印花和多层叠穿需要 SCHP 类的语义解析，本地没有权重。
