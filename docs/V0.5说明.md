# 本地再铸 V0.5 说明

产品名称使用「本地再铸」，不模仿任何第三方软件的名称、品牌或界面布局。
本阶段建立在 V0.1 的导入提取与 L1 人物替换之上，不拆掉原有路径。

## 已实现

- **四级模板**（剧本 / 角色 / 场景 / 分镜）：以文件夹 + JSON 存放，并写入 `templates` / `template_packs` 表（含 level 与 version）。任务记录所用模板版本，工作目录会钉住一份 `templates_used/`，重跑老剧不会被新模板污染。
- **剧本模板**维护分段结构、旁白规则（旁白只在开头段落，其后只贴对白）、字幕样式、导出规格（默认竖屏 720×1280、约 90 秒）。**全局风格锁只写在剧本模板**，执行时自动拼到每一镜。
- **硬校验**（保存与执行前）：一镜两个以上主动作直接报错；多人镜头必须每人绑参考图，缺什么会写成「缺少 xx.png」，并停在待补资料 / 待人工检查，不会开跑；打架类镜头默认最多两人同框。
- **管线顺序写死**：先静音画面，再贴轨。模板只能改对白内容，不能改这个顺序。
- **模板编辑器**：桌面独立窗口，编辑四级、校验、导入/导出模板包、把当前包套到所选剧目。
- **第二条入口：按剧本生成新集**。解析分镜文本/JSON 与对白表，生成 `shots`（镜头号如 F1-L1）。两条入口在人物替换 / 合成导出处汇合。
- **对白字数预检**：按字数与镜头时长比较，超了会提示改分镜或拆句，**不会默认加速音频**。
- **生成适配**：若设置了可访问的 ComfyUI HTTP API，会提交模板包里的工作流 JSON 并收回结果。若 ComfyUI 不可用，则用参考静帧做 Ken Burns / 定格，写成静音镜头再贴轨。界面与 README 明确称为「**分镜预览成片**」，不是完整图生视频，也不是默认的 Wan / AniCrafter。
- **配音可插拔**：尝试本机可选引擎（如已安装的 edge-tts / pyttsx3）；否则可导入对白 wav 表；再否则跳过配音，仍写出并（可选）烧录 SRT，日志会记录跳过。不要求云 TTS 密钥。旁白与对白遵循剧本模板规则。
- **成本表**：每个任务从 `runs` 表写出 `cost.xlsx`（步骤、本机时长、可选云费用、模型、状态），数字与日志一致。桌面有「成本表」窗口。
- **剪映工程导出**：在交付目录写出 `jianying_draft/`（`draft_info.json`、`project.json`、`timeline.xml`、媒体副本与说明）。格式未对某一确定剪映版本做打开验证，**不承诺在每个剪映版本里都能打开**，但文件一定会生成。
- **质量标记与终检队列**：生成/替换后检查人脸特征漂移、可选服装/风格标记、对白超时；终检窗口列出原因并支持单镜重跑。
- **CPU/GPU 错峰**：默认仍是 1 个 GPU 任务；GPU 在跑第 N 集的替换/生成时，CPU 可以预处理第 N+1 集的扫描/切镜/OCR/ASR。可取消。
- **底部阶段条**保留 01–05，并增加：模板套用、按剧本生成（先静音）、贴轨与字幕、成本表 / 剪映工程导出。上传是单独的可选最后一步，默认关闭。

## 可运行示例

`examples/开局即打-第1集模板` 与 `examples/开局即打-示例剧目` 来自用户自己的第 1 集制作材料（分镜、对白、角色参考），不是第三方产品包。约 90 秒、旁白只在 F1、无 BGM、一镜一动作。

在桌面工作台点「按剧本生成新集」，模板包选上述目录即可。未连接 ComfyUI 时得到的是「分镜预览成片」。若某句对白相对镜头过长（例如较密的怒斥台词），会按预检拦住，请改分镜或拆句，不要加速。
